## Generated content

Generated by the game's own code (`src/sprite_gen.cpp`, `src/assets.cpp`, `src/audio.cpp`) and covered by its [MIT licence](LICENSE):

- procedural civilians, used only when the civilian atlases are missing;
- street furniture, the metro train and building window masks;
- light, flare and smoke textures;
- all sound effects.

### CJ-004 source sprite sheets

The [civilian and motorbike source art](assets/art/cj004/README.md) was generated with the built-in image generation tool on 2026-10-07. Civilian sheets and earlier idle masters, including v3, are rejected experiments; [v4 idle](assets/art/cj004/civilian-idle-master-v4.png) awaits user review and has no generated animation groups. The motorbike designs are accepted, and since 2026-10-07 the game uses their six exports (`assets/vehicles/*-empty.png` and `*-ridden.png`) in place of the procedural motorbikes; the user accepted them in a playtest on 2026-10-08. The civilian art is not used in the game. Since 2026-10-08 the civilians are rendered from MakeHuman CC0 assets (via the GPL-3 MPFB add-on, a tool only) and animated with the Quaternius Universal Animation Library (CC0); the game uses the [rendered civilian atlases](assets/art/cj004/README.md#full-set-2026-10-08) since 2026-10-08. Exact [generation and edit prompts](assets/art/cj004/prompts.json) and the [smaller-group workflow](assets/art/cj004/civilian-prompts-v2.md) are preserved. Earlier civilian development used the Survivor player by Riley Gombart (CC-BY 3.0) as a camera/style reference and this project's procedural civilian art as a pose reference; the latest idle uses a locally constructed upright pose guide. Keep the existing Survivor attribution. The motorbike sheet was generated without a third-party image input. No third-party CC0 licence is claimed for the generated artwork.
