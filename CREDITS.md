## Generated content

Generated by the game's own code (`src/sprite_gen.cpp`, `src/assets.cpp`, `src/audio.cpp`) and covered by its [MIT licence](LICENSE):

- street furniture, the metro train and building window masks;
- light, flare and smoke textures;
- all sound effects.

### CJ-030 loading screen background

The [final loading background](docs/design/loading-background.md) was created with OpenAI ImageGen and approved by the user on 2026-10-09. The accepted source is `docs/images/cj030-loading-background.png`; the runtime copy at `assets/ui/loading-city.png` preserves its bytes and SHA-256 `421c2892e1fc3e0b81b078b0d7b40d9508281664b7454f0aa921aaf7f7f0a152`. Native dimensions and provenance are recorded in the asset document. The separate live interface is drawn by the game.

### CJ-030 loading screen wordmark

The transparent [loading wordmark](assets/ui/loading-logo.png) was generated with OpenAI ImageGen on 2026-10-09. Production brief: a separate two-line CONCRETE / JUNGLE wordmark with tall condensed uppercase lettering, warm ivory/amber accents, restrained concrete/metal texture, clean edges and a transparent background. The PNG's SHA-256 is `c89de0d571ece0fb6222d18bd7d92206b696b2a15f70fbf0a0924e52d5a8f7c8`. No third-party asset licence is claimed for this generated artwork.

### CJ-004 source sprite sheets

The [motorbike source art](assets/art/cj004/README.md) was generated with the built-in image generation tool on 2026-10-07 without a third-party image input; the user accepted the designs, and the game uses their six exports (`assets/vehicles/*-empty.png` and `*-ridden.png`). The generated civilian sheets and idle masters were rejected and, with the old player sprites, removed on 2026-10-11 ([ADR-0009](docs/adr/0009-required-character-atlases.md)); they remain in the Git history. The exact [generation and edit prompts](assets/art/cj004/prompts.json) are preserved. No third-party CC0 licence is claimed for the generated artwork.
